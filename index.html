上下文感知的AI浏览器助手 - 与您的浏览器数据实时对话

下载 omni-context-ai.zip

快速安装

1. 下载 omni-context-ai.zip 文件
2. 解压得到 dist 目录
3. 打开 Chrome 浏览器
4. 访问 chrome://extensions/
5. 启用"开发者模式"
6. 点击"加载已解压的扩展程序"
7. 选择 dist 目录完成安装

核心功能

强大的工具调用能力

Omni Context AI内置了多种实用工具，包括网页内容提取、视口内容获取、标签页控制、书签信息获取和浏览历史记录获取。AI可以根据对话内容智能选择和调用合适的工具，帮助您更高效地完成任务。

透明的思考过程

AI的推理过程完全透明可见，您可以清楚地看到AI如何分析问题、制定解决方案。这种透明度让您更好地理解AI的决策逻辑，增强对AI答案的信任。

专业的数学公式支持

完美支持LaTeX格式的数学公式渲染，无论是简单的代数表达式还是复杂的微积分方程，都能以专业的排版效果展示，是学生和研究人员的得力助手。

丰富的图表可视化

支持Mermaid图表语言，可以直接在对话中创建流程图、时序图、甘特图等多种图表。让复杂的信息结构一目了然，提升沟通效率。

AI 工具

Omni Context AI 内置10个浏览器工具，AI助手可智能调用这些工具实时获取浏览器数据、控制标签页、提取网页内容、管理书签和浏览历史

Get Page HTML

提取网页主要内容（HTML格式）

Get Page Text

提取网页主要内容（纯文本格式）

Get Page Metadata

提取网页元数据（meta标签）

Get Viewport Content

提取当前可视区域的内容

Get Tabs

获取所有打开的标签页信息

Open URL

在新标签页中打开URL

Close Tab

关闭指定标签页

Switch Tab

切换到指定标签页

Get Bookmarks

获取浏览器书签列表

Get Browse History

获取浏览器访问历史

支持的AI服务提供商

Omni Context AI支持多个主流AI服务提供商，特别优化了以下三个顶级选择

智谱 Coding Plan

智谱AI推出的专为编程优化的模型计划，提供强大的代码生成和理解能力，是国内领先的AI编程助手

Kimi For Coding

月之暗面推出的Kimi专门为编程场景优化，支持超长上下文（最高支持200K tokens），理解能力强

其它兼容API

支持所有OpenAI和Anthropic兼容API的提供商，包括OpenRouter、MiniMax-M2、KAT Coder、豆包编程模型等，灵活接入各种AI服务

特别推荐

我们强烈推荐使用 智谱 Coding Plan、Kimi For Coding，因为它们为开发者和专业用户提供了最优化的体验，包括出色的代码理解能力、长上下文支持和灵活的模型切换功能。
